Chemotherapy-Induced-Cardiotoxicity-Prediction

Overview

This project predicts Chemotherapy-Induced Cardiotoxicity (CIC) using Deep Learning techniques on Temporal Dynamic Imaging (TDI) data.

Technologies Used

- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Pandas
- Flask
- SQL

Models Implemented

- CNN + LSTM
- CNN + GRU
- CNN + Transformer

Results

- Best Model: CNN + Transformer
- Accuracy: 99%
